## 👋 项目简介

GymMane 是一款开源力量训练记录工具。在交互式人体肌肉图谱上直观点击你要训练的部位，按组记录次数与负重，伴随清晰明确的间歇闹铃声高效休息，所有数据分析 — 包括容量、个人纪录（PR）、打卡连胜及肌群分布，全部如实反映**你自己的真实训练**。绝无虚饰。

> [!TIP]
> **完全属于你。** 无账号、无广告、无订阅 — 甚至**没有网络权限**。每一条训练记录都安全地保存在你的本地手机中。

<div align="center">
<br/>
<b>500+</b> 训练动作 &nbsp;·&nbsp; <b>6</b> 款实用计算器 &nbsp;·&nbsp; <b>100%</b> 离线运行 &nbsp;·&nbsp; <b>0</b> 网络权限
</div>

## ✨ 核心特性

<table>
<tr>
<td width="50%" valign="top">

### 🏋️ 训练记录

- **交互式人体图谱**（正反两面）— 点击即选目标训练肌群
- 自动智能预选推荐动作组合，亦可随心调整每组细节
- 次数、重量以及专属**组间休息计时器**（支持自定义铃声与动作级专属时长）
- **多样化组别类型** — 热身组、正式组、递减组、力竭组（热身组自动排除在正式容量之外）
- 装片时自动为你计算好**单边杠铃片挂片方案**
- 进行中的训练具备抗重启能力 — 随时从中断处继续
- **训练计划**支持自由拖拽排序及按星期日程编排

</td>
<td width="50%" valign="top">

### 📊 进度分析

- 总容量、打卡连胜天数、每周目标环与 **PR 个人纪录**
- GitHub 风格的**训练热力日历**、每周出勤节奏与生涯数据总计
- 包含估算 1RM 的**力量增长曲线**，及近 30 天肌群训练分布
- **身材相册** — 正面、侧面、背面三大角度追踪，支持双日左右同屏滑动对比与拍照提醒
- 不想拍照？相册亦可**以肌群热力图呈现**
- 体重及 **10 项身体围度记录**，均配备独立历史趋势曲线
- 离线生成精美**打卡卡片** — 连胜记录、轰炸肌群或前后身材对比

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📚 动作库与实用工具

- **500+ 内置动作**，均配备动作动画与分步指导教程
- 搜索、按肌群/器械/难度多维筛选、收藏及**自定义新建动作**
- 支持为**任意动作**替换为你自己的实拍照片、GIF 或演示视频
- **场地管理** — 勾选各场地现有器械，智能仅显示当前场地可练动作
- 日历式**训练备忘日志** — 分类标记心得、计划、突破或伤痛，支持多媒体附件
- **6 款健身计算器** — 1RM、杠铃片、BMI、热量与宏量、体脂率、热身推算
- **3 款桌面小组件** — 训练动态、数据概览与肌群热力图

</td>
<td width="50%" valign="top">

### 🔒 数据安全与隐私

- 支持导出为 **CSV 表格** 或包含全部媒体的完整 **ZIP 备份**，随时导入恢复
- 无缝迁移自 **Hevy**、**Strong** 或 **FitNotes** — 兼顾训练历史与体重记录
- 无账号、无广告、无第三方统计 SDK — 甚至**没有请求 INTERNET 权限**
- 所有拍摄的照片、视频与备忘均安全保留在应用私有存储中
- 支持一键清空全部数据
- 支持明暗主题切换，公斤 (kg) 与磅 (lb) 自由设定
- 支持英语、西班牙语、意大利语和简体中文

## 📦 从其他应用迁移？

随心带着你的历史数据出发。GymMane 支持读取 **Hevy** 与 **Strong** 的训练及身体数据导出文件（CSV 或数据压缩包），以及 **FitNotes** 的完整备份（SQLite 数据库）。导入时会自动匹配动作库，已记录的条目会自动跳过去重。

| 来源应用 | 导入所需文件 |
|---|---|
| **Hevy** | `workout_data.csv`，及围度数据 zip 压缩包 |
| **Strong** | `strong.csv` |
| **FitNotes** | 完整的 `.fitnotes` 备份文件 (SQLite) |

<div align="center"><sub><b>设置 → 数据管理 → 从其他应用导入数据</b></sub></div>

## 🔒 隐私保证

> [!IMPORTANT]
> GymMane **绝不包含任何分析统计代码、广告 SDK 或联网代码**。应用在 Android 层面完全没有申请 `INTERNET` 网络权限，因此在物理机制上绝不可能向外发送你的任何训练与个人数据。唯一的外部行为是你在应用内主动点击的网页链接。

应用所申请的全部权限用途说明：

| 系统权限 | 申请原因与用途 |
|---|---|
| `POST_NOTIFICATIONS` | 显示休息倒计时及结束提醒 |
| `USE_EXACT_ALARM` | 毫秒级准时响铃，避免延迟 |
| `VIBRATE` | 计时结束震动提醒 |
| `WAKE_LOCK` | 熄屏状态下仍能准时唤醒响铃 |

## 🌍 国际化与翻译

GymMane 目前已支持英语、西班牙语、意大利语和简体中文，热烈欢迎社区贡献更多语言。翻译资源位于 [lib/l10n](lib/l10n) 目录下的标准 ARB 文件中 — 每种语言一个独立文件。您可以在 GitHub 上直接编辑对应文件并提交 Pull Request。

完整翻译指南参见 **TRANSLATING.md**。
